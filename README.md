# کافه مدرسه — نسخه تستی خصوصی (V1)

پلتفرم نمایشی که دانش‌آموز دبیرستان دوره دوم را از داخل مدرسه به کافه‌های اطراف وصل می‌کند.

**سفارش امروز → تحویل فردا در زنگ تفریح انتخابی از طریق بوفه مدرسه**

---

## دسترسی

| صفحه | آدرس | رمز |
|------|------|-----|
| سایت اصلی | `/` یا `index.html` | `cafe1405` |
| پنل ادمین | `/admin.html` | `admin-cafe-v1` |

---

## ویژگی‌های این نسخه

- ورود ساده با نام + تیک تأیید والدین برای نوشیدنی‌های قهوه
- نقشه تهران (Leaflet + OpenStreetMap)
- ۲ مدرسه فرضی + ۶ کافه با مختصات واقعی‌نما
- فیلتر کافه‌های نزدیک (تقریباً ۵۰۰–۹۰۰ متر)
- منوی سه‌بخشی: قهوه (گرم/سرد)، بدون کافئین (گرم/سرد)، کیک و شیرینی
- ثبت سفارش نمایشی با انتخاب زنگ تفریح و شمارنده حداقل
- خط‌زمانه روزانه مطابق طرح
- پنل ادمین برای ویرایش منو و تنظیم حداقل تعداد سفارش در هر زنگ
- ذخیره‌سازی محلی (localStorage) — بدون بک‌اند

---

## استقرار روی Cloudflare Pages

1. این پوشه را به یک ریپازیتوری GitHub پوش کنید.
2. در Cloudflare Dashboard → Pages → Create project → Connect to Git.
3. Framework preset: **None** (یا Static)
4. Build command: خالی بگذارید
5. Build output directory: `/` (ریشه پروژه)
6. Deploy

یا با Wrangler:

```bash
npx wrangler pages deploy . --project-name=cafe-madrese
```

## داده ساختگی

**مدارس:**
- دبیرستان سلام تجریش (تجریش)
- دبیرستان نمونه ونک (ونک)

**کافه‌ها:** دزاشیب، قهوه‌خانه تجریش، باغ‌فردوس، ونک، روستر آناهیتا، چهارراه

---

## نکات نسخه تستی

- بدون پرداخت واقعی
- بدون پیامک
- داده واقعی دانش‌آموز ذخیره نمی‌شود
- حداقل تعداد سفارش در ادمین قابل تنظیم است (پیش‌فرض ۳)
- اگر حداقل پر نشود، در این نسخه سفارش همچنان ثبت می‌شود (فقط هشدار نمایشی)
